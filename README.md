# ConversaoTemperaturaGo

Programa em Go para conversão de temperatura via terminal.

## Funcionalidades

- Celsius → Fahrenheit
- Fahrenheit → Celsius
- Celsius → Kelvin
- Kelvin → Celsius

## Como executar

```powershell
go run main.go
```

## Como compilar

```powershell
go build
```

## Uso

Ao rodar o programa, um menu interativo é exibido no terminal:

```
=== Conversor de Temperatura ===
1 - Celsius para Fahrenheit
2 - Fahrenheit para Celsius
3 - Celsius para Kelvin
4 - Kelvin para Celsius
0 - Sair
```

Escolha a opção desejada digitando o número correspondente e informe o valor da temperatura quando solicitado (aceita ponto ou vírgula como separador decimal).
